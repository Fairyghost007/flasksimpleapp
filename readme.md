# Application de blog produit en Flask

C'est une application de blog simple ou je presente mes produits construits avec Flask, un framework web Python. L'application a les fonctionnalites suivantes :

- Inscription et connexion d'utilisateurs
- listing, Creation et suppression de posts de produit
- Authentification et autorisation d'utilisateurs

L'application est construite avec les technologies suivantes :

- Flask
- Flask-SQLAlchemy
- Flask-Bcrypt
- Flask-Login
- Flask-WTF
- Flask-Markdown
- Email-Validator
- Pillow
- Requests
- Selenium
- Lorem-Text

L'application est configuree pour s'executer sur le port 5000. Pour lancer l'application, naviguez jusqu'au repertoire du projet et executez `python run.py`. Pour reinitialiser la base de donnees, executez `python run.py -r`. Pour lancer l'application en mode debug, executez `python run.py -d`.
